# 0001 描画ライブラリと再描画方式（ステップ0の結果）

- 日付：2026-10-24
- 状態：**PCは確定、スマホ・タブレットは実機確認待ち**
- 試作：`prototypes/renderer/`（計測：`npm run bench`、`node bench/osmd.mjs`）

## 結論

1. 描画ライブラリは **Verovio（WASM、6.3.0）** にする。OSMDは採用しない
2. 楽譜は**数小節ずつの「チャンク」に分けて描画**し、表示中のチャンクだけ描く（縦に続く表示と相性がよい）
3. チャンクの大きさは「パート数 × 小節数 ≒ 36」を目安にする：`clamp(floor(36 / パート数), 2, 16)` 小節
   （18パートのオーケストラ → 2小節、木管5重奏 → 7小節、弦楽四重奏 → 9小節）
4. 編集の反映は2通りに分ける
   - **音高だけの変更**：Verovioの編集API（`edit` の `set` で `pname`/`oct`）＋ `redoPagePitchPosLayout()` で、レイアウトし直さずに音の縦位置だけ計算し直す。画面には**変わった小節の `<g class="measure">` だけを差し替える**
   - **それ以外（音価・臨時記号・追加・削除など）**：そのチャンクだけを読み込み直して描画し、チャンクのSVGを差し替える
5. 「ページ」レイアウト（用紙どおり）とPDFは、編集中の表示とは別に、書き出し時に全体を描く（時間がかかってよい処理として扱う）

## 計測結果

計測環境：クラウドの開発コンテナ（Intel Xeon 2.8GHz・4コア）、ヘッドレスChromium。
「タブレット」「スマホ」は画面サイズ（1024×1366、390×844）とタッチを再現し、**メインスレッドのCPUを4倍遅く**したもの。
**Chromeの「CPUを遅くする」設定はWeb Worker（Verovioの処理）には効かない**ため、スマホ・タブレットの数値は実機より良く出ている可能性がある。

### 丸ごと描く方式（不採用）

合成オーケストラ（18パート・500小節）をNodeで計測。

| 処理 | 時間 |
| --- | --- |
| 全体の読み込み（`loadData`） | 約10.9秒 |
| 全体のレイアウトし直し（`redoLayout`） | 約6.7秒 |
| 音高変更＋`redoPagePitchPosLayout`＋1ページ描画 | 約22ミリ秒 |

読み込みだけでPCの目標（5秒）を超える。音高の変更は速いが、それ以外の編集のたびに数秒かかる。

### OSMD（不採用）

PCの画面サイズ・CPU等倍。OSMDには一部だけを描き直す仕組みがなく、編集のたびに全体を描き直す。

| ベートーヴェン Op.18-1（4パート・約950小節） | 2.6秒 | 6.0秒 | **4.8秒** |

### 分かったこと

- MusicXMLの `<note id="...">` はVerovioのSVGの `id` にそのまま残る。**タップした音符の特定はid経由でできる**
- 編集の遅さの大半はVerovioではなく**画面側（SVGの差し替えと再描画）**だった。小節だけの差し替え、`content-visibility: auto`、`contain` で大きく減った
- VerovioのSVGは描画ごとにグリフ定義のid接尾辞が変わる（`#E0A4-<svgId>`）。小節だけ差し替えるときは接尾辞を書き換え、表示中のSVGにないグリフが必要なときはチャンクごと描き直す
- VerovioのWASMを含むWorkerは約8.2MB（gzipで約2.4MB）。Service Workerでのキャッシュが必須
- 最初の表示のうち、MusicXMLの分割（ブラウザのDOMParser）に約1秒かかっている。本番では内部データから直接チャンクを書き出すので短くなる見込み
- MusicXMLの代わりにMEIで渡すと、読み込みが約13%速い（Node計測）。本番でチャンクを書き出すときはMEIで直接書く選択肢がある

## 今後の設計への影響

- `src/render/` は「チャンク単位で描く」インターフェースにする（`renderChunk(range) → SVG`、`patchPitch(noteId) → 小節SVG`）
- 内部データ → チャンク（MusicXMLまたはMEI）の書き出しを `core/musicxml` に置く。チャンクの頭には、その時点の調号・拍子・音部記号・移調を必ず入れる
- 音符の `id` は内部データの `Note.id` をそのまま使う（和音の各音は `NoteHead.id`）
